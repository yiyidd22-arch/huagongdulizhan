# 独立站 — 快速命令

## 改网站代码后上线

```powershell
cd d:\huagongdulizhan
git add .
git commit -m "更新说明"
git push origin master
```

Cloudflare 自动构建，约 2–5 分钟：https://huagongdulizhan.pages.dev

## 本地开发

```powershell
cd d:\huagongdulizhan
npm install
npm run dev
# http://localhost:4000
```

本地看新闻需先同步：`npm run sync:news`
